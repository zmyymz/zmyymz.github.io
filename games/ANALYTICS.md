# GoatCounter 游戏访问统计

后台：https://zmyymz.goatcounter.com/ 。公共接收地址和脚本地址在 `js/analytics/config.js`，不需要也不应填写 API 密钥。

## 口径

首页、游戏列表、童年合集和所有游戏 index.html 均统计页面浏览。每次正常加载页面由 GoatCounter 自动上报一次，不额外统计卡片点击。刷新、直接链接进入也会触发；广告拦截、网络失败、服务端过滤可能造成漏计，数据不等于开始游玩或真实人数。后台看页面浏览量和各游戏路径排行，而非独立访客指标。

`?v=...` 等查询参数及锚点不参与页面路径，`/index.html` 合并到目录地址。旧不蒜子已移除，不迁移历史数字。公开页不显示累计数；后台采集须部署后验证。

## 本机排除

游戏列表底部「统计设置」可排除/恢复当前浏览器，使用 `game-analytics-disabled` 本地标记，兼容此前草稿的排除标记。设置仅影响之后新加载的页面，已打开的其他游戏页需要刷新。每个设备、浏览器分别设置，清理浏览器数据后重设。本地预览和非正式域名不加载统计；无法读取本地存储时也不加载。

## 同步游戏

现有 tools/sync-*.py 自动调用 analytics_hooks.install，仅在博客副本追加统计脚本，不修改源项目。手动复制或 Godot 导出后运行 `python3 tools/install-analytics.py`。标记保证重复执行不重复插入。新增入口统一用相同流程。

本地验证涵盖正式域名开关、排除标记、路径规范化、重复加载保护和页面脚本覆盖。正式上线后需要打开两款游戏并在后台核对路径；未上线前不能声称数据采集成功。无需公开后台或提供管理密码。
