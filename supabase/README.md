# 游戏点赞

在 Supabase 项目的 SQL Editor 中执行 `game-likes.sql`，然后刷新本地游戏列表。配置位于 js/likes/config.js，仅公开 publishable key。无需开启公开表读写；表启用 RLS 且不允许 anon/authenticated 直接操作，只开放两个受限 RPC。不要把 service_role、secret key 或数据库密码放进网页。

游戏路径是稳定 ID，改显示名称不影响点赞。一个浏览器本地生成随机 UUID，同一游戏一条点赞记录；重复提交点赞幂等，取消只删除该标识的记录。总数从数据库读取，不使用假的默认数。网络失败时不会乐观增加计数。

匿名点赞仅轻量去重：清理数据或换浏览器后可再次点赞，恶意用户也能生成新 UUID。此方案无强防刷、身份认证或服务端请求频率限制；推广流量大时应加 Edge Function 限流/验证码。不能用于抽奖或比赛计票。浏览器本地状态不会跨设备同步。

只有 localhost / 127.0.0.1 且 URL 带 `?likes-preview=1` 才启用纯本机演示，显式显示预览提示，数据不会发送 Supabase，与真实点赞分开保存。线上不支持演示模式。

数据库未初始化时前端显示“点赞服务尚未就绪”，按钮禁用，不影响游戏入口。初始化后需验证点赞、刷新、取消和第二浏览器读取累计数；本地演示通过不等于数据库写入验证。
